Install the app

Turn the site into
an app on your phone

AstroRoast lives on the web at app.astroroast.app. Open it in your browser, then save it to your home screen so it behaves like an app.

1. Open the site 2. Share or menu 3. Add to Home Screen / Install

iPhone / iPad

Use Safari for the smoothest install flow on iOS.

  1. 1Open app.astroroast.app in Safari.
  2. 2Tap the Share icon in the bottom toolbar.
  3. 3Choose “Add to Home Screen”.
  4. 4Confirm the name, then tap Add.

You’ll get an app icon on your home screen that opens AstroRoast full screen.

Android

Chrome will usually offer the install prompt automatically.

  1. 1Open app.astroroast.app in Chrome or another supported browser.
  2. 2Tap the menu button in the browser.
  3. 3Select “Install app” or “Add to Home screen”.
  4. 4Confirm the install and launch it from your home screen.

If the install prompt appears, you can use it directly instead of the menu.
